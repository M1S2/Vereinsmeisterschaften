Dictionary<Person, List<int> > Vereinsmeisterschaften.Core.Analytics.AnalyticsModuleDistancesBetweenStarts.DistancesBetweenStartsPerPerson
get

Distances between the starts (value) per person (key).

Only persons with more than one start are part of this list (otherwise a distance can't be calculated). A distance of 1 means the starts are consecutive. A lower value isn't possible. The list is ordered ascending by the minimum of each start distances per person.
